# Bahbahani Live Platform
Node.js + Express + Socket.IO starter واقعی برای ثبت‌نام، پنل، ساخت جلسه، جلسه خصوصی، لینک جلسه و چت زنده.

اجرا:
1. Node.js نصب شود
2. npm install
3. npm start
4. http://localhost:3000

برای انتشار عمومی باید HTTPS، دیتابیس واقعی، OTP، TURN server و احراز هویت امن اضافه شوند. رمز ادمین را با متغیر محیطی ADMIN_PASSWORD تنظیم کنید.
